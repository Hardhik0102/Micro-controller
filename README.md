# Micro-controller
# Educational Microcontroller Simulator with Process Scheduling

## Project Title
Educational Microcontroller Simulator with Process Scheduling

## Problem Objective
The main aim of this project is to create a simulator for the MS51FB9AE microcontroller. It will show how the processor runs instructions, uses memory and stack, and handles GPIO, timers, and interrupts. It will also show how multiple programs can be managed using CPU scheduling like FCFS, Round Robin, and Priority Scheduling.

## Problem Statement
We have to build a software simulator for the Nuvoton MS51FB9AE microcontroller. It should simulate basic parts like registers, memory, stack, program counter, instructions, GPIO, timers, and interrupts. It should also manage multiple programs as processes using PCB, ready queue, and context switching, with FCFS, Round Robin, and Priority scheduling.

## Project Scope
 This project will simulate the important parts of the MS51FB9AE microcontroller. It will include memory, stack, GPIO, timer, interrupts, and some basic instructions. It will also manage multiple programs as processes using FCFS, Round Robin, and Priority scheduling. The simulator will allow us to load, run, reset, and execute programs step-by-step, while showing basic performance details like waiting time, turnaround time, response time, and CPU usage.

## Microcontroller Being Simulated
Nuvoton MS51FB9AE (it is based on the 8051 core, 8-bit microcontroller).

## Selected Programming Language
Java

### Reason for Selection
Java was the language suggested for this project, and I also feel comfortable writing object-oriented code in it. 

### Advantages for This Project
 Since Java is object-oriented, it becomes easy to represent Registers, Memory, PCB, Scheduler etc as different classes.
 Java already has built-in data structures like Queue, Stack and LinkedList which are useful for the ready queue and process handling.
 If needed later, a simple UI can be made using Java Swing or JavaFX.

### Limitations
- Java code can get a bit lengthy compared to some other languages.
